**Выделенный сервер Factorio для Windows, который играет ваши собственные сохранения.** Вы выбираете сейв из папки игры, а flserver запускает его на безоконном режиме уже установленной у вас игры. Когда сервер останавливается, прогресс возвращается в тот же сейв, и его можно снова открыть в игре.

Без отдельной загрузки сервера, без Linux и Docker. Один небольшой `flserver.exe`.

## Что внутри

- **Ваши сейвы и моды.** Сохранения и моды берутся из папок самой игры, вместе с Space Age и другими дополнениями. Версия сервера всегда совпадает с версией игры.
- **Лёгкий.** Без окна, графики и звука: около 370 МБ памяти на карту Space Age против 4 ГБ у самой игры. Пока никто не подключён, мир стоит на паузе.
- **Бережёт сейвы.** Резервная копия перед каждым запуском, проверенная копия карты, с которой идёт работа, и оригинал не перезаписывается, если игра успела его изменить.
- **Переживает сбои.** Если отключили свет или процесс убит, при следующем запуске последний автосейв возвращается в игру.
- **Консоль и удалённое управление.** Команды можно вводить в окне сервера или отправлять из другого: `flserver status`, `flserver cmd /players`, `flserver stop`.
- **Остановка пустого сервера** через N минут без игроков, по желанию.
- **Сообщения на русском и английском**, язык выбирается по языку Windows.

## Быстрый старт

Нужны Windows 10 или новее и установленная Factorio 2.0 (GOG, Steam или zip-версия).

Скачайте [flserver.exe](https://github.com/ospab/factorio-lightserver/releases/latest/download/flserver.exe) со страницы [Releases](https://github.com/ospab/factorio-lightserver/releases), положите в отдельную папку (настройки и файлы он хранит рядом с собой) и запустите. Файл не подписан, поэтому Windows SmartScreen может предупредить; контрольная сумма указана на странице релиза. Или соберите сами, нужен Go 1.24 или новее:

```powershell
git clone https://github.com/ospab/factorio-lightserver
cd factorio-lightserver
go build -trimpath -ldflags "-s -w" -o flserver.exe .
.\flserver.exe
```

Программа покажет сейвы, новые первыми. Enter запускает самый новый, или введите номер. Когда она напишет, что сервер работает, подключайтесь из игры: **Сетевая игра → Подключиться по адресу**, `localhost` или адрес, который сервер напечатает для вашей сети.

Чтобы сохранить мир и выйти, введите `stop` или нажмите Ctrl+C. Если этот мир сейчас хостит сама игра, сначала закройте его: оба не могут занять UDP-порт 34197.

```powershell
.\flserver.exe start my-factory      # сейв по имени
.\flserver.exe list                  # список сейвов
.\flserver.exe status                # из другого окна
.\flserver.exe stop
```

## Чем он не является

Это не переписанный Factorio. Карту считает `factorio.exe` в безоконном режиме, как и у официального сервера, поэтому память определяется движком, а не более лёгкой программой. flserver отвечает за всё вокруг: выбор сейва, его сохранность и управление процессом. Поддерживается только Windows; проверено на Factorio 2.0.72 с Space Age.

| Путь | Что |
|---|---|
| `main.go` | команды, список сейвов, удалённое управление |

| `saves.go` | проверка сейвов, копии, возврат прогресса, синхронизация модов |
| `config.go` | `flserver.json`, поиск игры, состояние сессии |

| `windows.go`, `lang.go` | вызовы Windows, язык |
| `docs/` | документация на английском (`en/`) и русском (`ru/`) |
