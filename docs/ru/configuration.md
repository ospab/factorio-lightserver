# Настройки

[English](../en/configuration.md) · [Документация](../README.md)

У flserver два файла настроек. `flserver.json` — самого flserver, лежит рядом с `flserver.exe`. `data\server-settings.json` — настройки сервера Factorio.

## flserver.json

Создаётся при первом запуске со значениями, найденными на вашем компьютере. Редактируйте любым редактором; читается при каждом запуске.

| Поле | По умолчанию | Значение |
|---|---|---|
| `game_dir` | находится сам | Папка игры, в которой есть `bin\x64\factorio.exe`. |
| `saves_dir` | `%APPDATA%\Factorio\saves` | Откуда читаются сейвы и куда возвращается прогресс. Для zip-версии игры — её собственная папка `saves`. |
| `mods_dir` | `%APPDATA%\Factorio\mods` | Откуда копируются моды и их настройки. |
| `save` | пусто | Сейв, который запускает простой `flserver`. Пусто — спрашивать. |
| `port` | `34197` | UDP-порт игрового сервера. |
| `bind` | пусто | Адрес, на котором слушать. Пусто — все интерфейсы; `127.0.0.1` оставляет сервер доступным только с этого компьютера. |
| `sync_back` | `true` | `true`: прогресс возвращается в сейв, который вы запустили. `false`: всегда в новый файл рядом. |
| `backups` | `10` | Сколько резервных копий каждого сейва хранить в `data\backups`. Не меньше 1. |
| `idle_stop_minutes` | `0` | Остановить сервер, если столько минут нет игроков. `0` — никогда. |
| `lang` | `auto` | Язык сообщений: `en`, `ru` или `auto` — по языку Windows. |

В путях используйте прямые слэши или удвоенные обратные: `"D:/Games/Factorio"` или `"D:\\Games\\Factorio"`.

## Папка data

Всё, что flserver создаёт во время работы, лежит в `data\` рядом с программой, так что её можно удалить и начать с чистого листа. Ваши сейвы и моды не меняются, кроме случаев, описанных в [Сохранениях](saves.md).

| Путь | Что |
|---|---|
| `world.zip` | Копия сейва, с которой работает сервер. |
| `saves\` | Собственные автосейвы сервера. Они не засоряют папку игры. |
| `backups\` | Копия сейва, сделанная перед каждым запуском. |
| `mods\` | Копия ваших модов. |
| `server-settings.json` | Настройки сервера, см. ниже. Создаётся один раз, дальше ваш. |
| `server-adminlist.json` | Админы. Копируется из игры при первом запуске, дальше ваш. |
| `config.ini` | Заставляет игру читать данные из `game_dir` и писать в `data\`. Перезаписывается при каждом запуске. |
| `session.json` | Отмечает работающую или прерванную сессию. Удаляется, когда прогресс вернулся в игру. |
| `factorio-current.log` | Лог игры. Сюда стоит смотреть, если сервер не запускается. |

## server-settings.json

Это тот самый файл, который игра описывает как `server-settings.example.json` в своей папке `data`; каждое поле там расписано. Файл, который создаёт flserver, отличается от примера в таких местах:

| Поле | Значение | Зачем |
|---|---|---|
| `name` | `Factorio server` | Поменяйте. |
| `visibility` | `public: false`, `lan: true` | Не попадает в публичный список серверов, объявляется в локальной сети. Для публичного списка нужны `username` и `token` с factorio.com. |
| `require_user_verification` | `false` | Зайти может любой и под любым именем. См. ниже. |
| `autosave_interval`, `autosave_slots` | `5`, `3` | Автосейв каждые 5 минут в папку `saves\` сервера. Ими пользуется [восстановление после сбоя](saves.md#восстановление-после-сбоя). |
| `auto_pause` | `true` | Пока никто не подключён, мир стоит на паузе. |
| `allow_commands` | `admins-only` | Команды с `/` в игре доступны только админам. |

Изменения вступают в силу при следующем запуске.

### Пароли и кто может зайти

При `require_user_verification: false` сервер не проверяет имена на factorio.com, поэтому любой, кто достучится до порта, может зайти под любым именем, в том числе под именем админа. Если сервер виден не только в вашей сети, сделайте одно из двух:

- задайте `game_password`, пароль, который игроки вводят при входе;
- поставьте `require_user_verification` в `true`, тогда именем могут пользоваться только настоящие аккаунты factorio.com.

### Админы

В первый раз flserver копирует `server-adminlist.json` из пользовательской папки игры (на уровень выше `saves_dir`). Дальше правьте `data\server-adminlist.json` или используйте `/promote ИМЯ` в консоли. Список — это JSON-массив имён:

```json
["ospab"]
```

## Моды

При каждом запуске flserver делает `data\mods` копией `mods_dir`: файлы модов `.zip`, `mod-list.json` и `mod-settings.dat`. Моды, которые вы удалили или отключили в игре, пропадают и с сервера. Распакованные моды (папки) не копируются; на каждый flserver выводит предупреждение. Дополнения (Space Age, Quality, Elevated Rails) входят в саму игру и включаются через `mod-list.json`.

У игроков должны быть те же моды тех же версий, что и на сервере. Недостающие моды игра скачивает с сервера, когда это возможно.

## Порты и брандмауэр

Серверу нужен UDP-порт `34197` (или ваш `port`).

- **Тот же компьютер или та же сеть.** Когда Windows спросит про `factorio.exe`, разрешите частные сети.
- **Через интернет.** Пробросьте UDP `34197` на роутере на этот компьютер и разрешите `factorio.exe` в брандмауэре Windows. Сначала задайте `game_password`.
- Сервер открывает ещё и порт RCON, но только на `127.0.0.1`, свободный, с новым случайным паролем при каждом запуске. Снаружи компьютера к нему не подключиться; flserver использует его для консоли и для `stop`.
