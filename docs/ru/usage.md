# Использование

[English](../en/usage.md) · [Документация](../README.md)

## Команды

| Команда | Что делает |
|---|---|
| `flserver` | То же, что `flserver start` без имени: показывает список и спрашивает сейв. |
| `flserver start [СЕЙВ]` | Запускает сейв. `СЕЙВ` — имя из списка (с `.zip` или без) или полный путь к `.zip`. Без имени берётся `save` из `flserver.json`, а если он пуст, показывается список. |
| `flserver start -v СЕЙВ` | То же, но в консоль идёт весь лог игры, а не только события. |
| `flserver list` | Список сейвов из `saves_dir`, новые первыми. |
| `flserver status` | Из другого окна: сколько сервер работает, какой сейв, сколько игроков, память. |
| `flserver cmd ТЕКСТ` | Из другого окна: выполнить команду на сервере, например `flserver cmd /players online`. |
| `flserver stop` | Из другого окна: сохранить мир и остановить сервер. |
| `flserver help` | Тот же список команд. |

Код выхода 0 при успехе и 1 при ошибке. Сообщения выводятся по-русски или по-английски, см. `lang` в [Настройках](configuration.md#flserverjson).

Одновременно работает один сервер. Второй `start` ответит, что сервер уже запущен.

## Выбор сейва

В списке указаны имя файла без `.zip`, время изменения и размер. Автосейвы игры (`_autosave1` и другие) тоже в нём. Запустить можно и их, но flserver никогда не записывает прогресс поверх автосейва: см. [Сохранения](saves.md#когда-оригинал-не-перезаписывается).

```powershell
.\flserver.exe start podw
.\flserver.exe start "C:\Backups\old factory.zip"
```

## Консоль сервера

Пока сервер работает, его окно — консоль:

| Вы вводите | Что происходит |
|---|---|
| `stop`, `quit`, `exit` | Сохраняет мир и останавливается. Ctrl+C и закрытие окна делают то же. |
| `/players`, `/players online`, `/time`, `/evolution` | Команды Factorio, ответ печатается. |
| `/server-save` | Сохраняет мир сейчас, дополнительно к автосохранениям. |
| `/promote ИМЯ`, `/demote ИМЯ` | Назначает игрока админом или снимает. |
| `/kick ИМЯ`, `/ban ИМЯ` | Убирает игрока с сервера. |
| другой текст | Появляется в чате игры как сообщение от `<server>`. |

Консоль показывает заходы и выходы, чат, кики, баны, ошибки и конец каждого сохранения. С `-v` видно всё.

## Из другого окна

`status`, `cmd` и `stop` находят работающий сервер по `data\session.json`, где flserver хранит адрес и пароль локального RCON-порта сервера. Поэтому они работают из любого окна PowerShell на том же компьютере под тем же пользователем Windows:

```powershell
.\flserver.exe status
.\flserver.exe cmd /players online
.\flserver.exe cmd "Сервер перезапустится через 5 минут"
.\flserver.exe stop
```

`stop` ждёт, пока сервер завершится и прогресс вернётся в сейв. Если окна, в котором сервер был запущен, уже нет, `stop` вернёт прогресс сам.

## Закрытие окна

Закрытие окна консоли считается командой `stop`. Windows даёт программе на это всего несколько секунд, поэтому на большой карте сохранение может не успеть. Тогда ничего не теряется: при следующем запуске будет найден последний автосейв и возвращён в игру (см. [восстановление после сбоя](saves.md#восстановление-после-сбоя)). Лучше использовать `stop`.

## Двойной щелчок

Запуск `flserver.exe` из проводника открывает окно со списком. Когда сервер остановился или случилась ошибка, окно ждёт Enter, чтобы вы успели прочитать последние строки.

## Без окна

Если указано имя сейва, ввод не нужен, поэтому подойдёт свёрнутое окно или планировщик заданий:

```powershell
Start-Process .\flserver.exe -ArgumentList 'start','podw' -WindowStyle Minimized
```

Позже остановите его командой `.\flserver.exe stop`. Для задания в планировщике укажите «Рабочая папка» с `flserver.exe` и добавьте в `flserver.json` параметр `idle_stop_minutes`, если сервер должен сам выключаться, когда на нём никого нет.
