# Начало работы

[English](../en/getting-started.md) · [Документация](../README.md)

## Что нужно

| | |
|---|---|
| Windows 10 или новее | flserver напрямую обращается к Windows (процессы, реестр, таблицы сети). Linux и macOS не поддерживаются. |
| Установленная Factorio 2.0 | GOG, Steam или zip-версия. Сервер запускает `bin\x64\factorio.exe` из неё, поэтому версии сервера и вашей игры всегда совпадают. Проверено на 2.0.72 с Space Age. |
| Go 1.24 или новее | Только чтобы собрать `flserver.exe`; кроме стандартной библиотеки зависимостей нет. |
| Около 0,5 ГБ свободного места | На диске с flserver и на диске с сейвами. С меньшим запасом запуск откажется: Factorio не может записать сейв на полный диск. |
| Около 400 МБ памяти | На карту Space Age. Для больших фабрик нужно больше. |

## Сборка

```powershell
git clone https://github.com/ospab/factorio-lightserver
cd factorio-lightserver
go build -trimpath -ldflags "-s -w" -o flserver.exe .
```

После этого `flserver.exe` можно положить куда угодно. Настройки и рабочие файлы он хранит рядом с собой (`flserver.json` и папка `data\`).

## Первый запуск

```powershell
.\flserver.exe
```

При первом запуске он ищет игру (записи GOG и Steam в реестре, библиотеки Steam, `Program Files`) и записывает найденное в `flserver.json`. Если не нашёл, скажет об этом: укажите там в `game_dir` папку, в которой есть `bin\x64\factorio.exe`, и запустите снова.

Затем он показывает сейвы, новые первыми:

```
  1. podw                                          23.11.2026 20:59    6.7 МБ
  2. _autosave3                                    23.11.2026 16:47    6.8 МБ
```

Enter запускает первый, или введите номер. Через несколько секунд:

```
Сервер готов за 2.1 с, память 372 МБ.
Подключение: localhost:34197, 192.168.1.20:34197
```

Windows может спросить, разрешить ли `factorio.exe` доступ к сети. Для друзей в вашей сети разрешите частные сети; для игры через интернет см. [Настройки](configuration.md#порты-и-брандмауэр).

## Подключение

В игре: **Сетевая игра → Подключиться по адресу**, затем `localhost:34197` на этом же компьютере или один из напечатанных адресов с другого. У всех должна быть та же версия игры и те же моды, что у сервера.

Если карту сейчас хостит сама игра, сначала закройте её: она держит UDP-порт 34197, и flserver ответит, что порт занят.

## Остановка

Введите `stop` в окне сервера, нажмите Ctrl+C или закройте окно. Сервер сохранит карту, и прогресс вернётся в выбранный сейв, см. [Сохранения](saves.md). Из другого окна:

```powershell
.\flserver.exe stop
```
